# Slide 2: Auto-scoring applicants (ML-based ranking)
- **Description:** 
  - Implement basic ML/AI algorithms to parse fresher skills
  - Automatically rank applications based on tech stack alignment
  - Surface top matches to mentors instantly
- **Effort estimate:** 4 Weeks
- **Dependencies:** Power Automate Premium (AI Builder) / Azure Cognitive Services
- **Business value:** Reduces manual screening time for managers and ensures better mentor-mentee fit

# Slide 3: Interview Scheduler Integration (Microsoft Bookings)
- **Description:** 
  - Embed Microsoft Bookings link in shortlisted notification
  - Allow freshers to pick available slots on the mentor's calendar
  - Automated calendar invites and reminders
- **Effort estimate:** 2 Weeks
- **Dependencies:** Microsoft Bookings licenses enabled for Mentors
- **Business value:** Eliminates back-and-forth emails for scheduling interviews
